Core features
⚡
Dual-Path Analysis
Fast path runs after each pull — damage table + death events, ~2 API calls per fight. Results render progressively as pulls complete.

Deep path paginated damage events filtered to avoidable spell IDs, with per-hit timestamps and dead-player context at moment of hit.
Fast path Deep path Progressive render Session cache
🧠
Claude AI Debrief
At the end of analysis, RaidLens calls the Anthropic API with the full player performance data, boss mechanics context, and every spec guide for specs present in the raid that night. Claude writes a targeted plain-English debrief aimed at the raid leader — not just stats, but patterns.
Anthropic API Pattern detection Dynamic prompt
📖
39-Spec Guide System
Every WoW spec has a guide in the repo. At analysis time, only the guides for specs present in the raid are fetched (parallel, cached). Claude sees the actual rotation, cooldowns, and spell IDs for every player's spec — so it knows the difference between a missed Bloodlust and a missed interrupt.
SimC APL embedded Wowhead-sourced IDs Lazy-fetched
🛡️
Defensive Tracking
Tracks personal defensive cooldown usage per player per pull using confirmed spell IDs. The killer signal: "died on 3+ pulls and pressed zero defensives." High-frequency AM (Ironfur, Shield Block, Death Strike) is included so the flag is conservative — no false accusations.
Per-pull tracking Zero-defensive flag 34 specs covered
🔇
Interrupt Tracking
Matches successful interrupts to completed boss casts by spell ID and timestamp window. A completed cast with zero matching interrupts = missed. 2+ = overlap (both fired too late). Per-player stats + per-pull timestamps shown in deep mode.
Timestamp matching Fearsome Cry · Essence Bolt
🔊
Dissonance Source Tracking
Mythic-only mechanic: Dissonance damages players based on proximity to the opposite realm. RaidLens auto-discovers the spell ID from the damage table and attributes damage source-side — the player who caused it, not just the one who took it.
Auto-discovered ID Source attribution Mythic only
